Entities

HTML entities are used to display reserved characters in HTML. For example, if you want to display the less than symbol (<), you can use the entity <.

Here are some common HTML entities:

  • < - Less than
  • > - Greater than
  • & - Ampersand
  •   - Non-breaking space
  • © - Copyright symbol

Here are some examples:

  • The price is 10 < 20.
  • Copyright © 2023.
  • This is an example   text.
  • Use & to display an ampersand.
