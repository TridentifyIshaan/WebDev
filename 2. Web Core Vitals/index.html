• Lighthouse tool is used to measure the performance of a website. It provides a score from 0 to 100, where 0 is the worst and 100 is the best.

    Web Core Vitals used as metrics

  1. First Contentful Paint (FCP)
  2. Largest Contentful Paint (LCP)
  3. Total Blocking Time(TBT)
  4. Cumulative Layout Shift (CLS)
  5. Speed Index

    Score based metrics

  1. Performance
  2. Accessibility
  3. Best Practices
  4. Search Engine Optimization (SEO)
  5. Progressive Web Apps (PWA)
